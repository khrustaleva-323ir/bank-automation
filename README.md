 # **Автоматизация банка** 

Краткое описание проекта автоматизации банковских процессов.

## Цель проекта

Автоматизировать ключевые процессы банка (учет клиентов, операции по счетам, формирование отчетов) с помощью программного решения.

## Задачи

1. Реализовать учет клиентов и счетов.
2. Обеспечить проведение типовых банковских операций (пополнение, перевод, списание).
3. Сформировать базовые отчеты( выписка по счету, сводный отчет).
4. Продемонстрировать применение автоматизации для снижения ручного труда и ошибок.
